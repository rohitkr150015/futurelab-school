FutureLab logo, favicon, installation icons, campus diagram and 3D model were authored for this build using code. Interface icons are Lucide. Fonts are self-hosted via `@fontsource/dm-sans` and `@fontsource/space-grotesk`; their license files ship in the dependency packages.

The supplied photos include existing school branding and identifiable students. This is a local fictional preview, not an assertion that FutureLab owns or operates those schools. Obtain the relevant asset license, school approval and student publication consent before public deployment. Replace any conflicting visible branding with approved school media.

`GRAPHICS`, third-party animation templates and other reference projects were reviewed as available resources but their licensed graphics/source were not imported. Motion, Three.js and CSS effects were implemented directly for this design.
